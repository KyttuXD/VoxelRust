# Trains - a mod that comes with the game, in its own folder.
#
# Rail track, carts that run on it, a locomotive that pulls them, and
# station furniture. `tag track <percent>` on a block makes it track and says how
# fast carts run on it; `tag station <seconds>` makes carts running by
# themselves stop and wait.
# Nothing here is part of the program. How vehicles move is the Vehicles
# mod's own code (mods/vehicles), which this needs switched on; a vehicle
# is a `vehicle` section naming a model, what it travels on (water, rail,
# land or air) and its numbers.
# Change them or add your own (docs/DATA.md). Switch the mod off in
# Settings > MODS, or delete its folder, and these are gone from the game.
