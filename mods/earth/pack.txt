# Earth - a mod that comes with the game, in its own folder.
#
# Worlds made from the real planet: heights from elevation data; land
# cover, roads, buildings and farmland from the map; the world map screen
# (M) and place-name notices. The program only knows how to lay map tiles
# out as terrain. Which tiles, what their colours mean and where a world
# may start is all written here, so another source or another planet's map
# is a matter of editing these lines. Switch the mod off in Settings > MODS
# (or delete its folder) and the EARTH terrain choice and the --earth
# option go away (worlds already made stay, but load no new ground).
# Needs the internet; see docs/EARTH.md.
#
# Map data (c) OpenStreetMap contributors. Elevation: Mapzen / AWS Terrain
# Tiles.

# Elevation tiles ({z} zoom, {x} and {y} tile numbers), their encoding and
# the deepest zoom they go to.
map heights https://s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png terrarium 14
# Map tiles: read for land cover, and shown on the map screen.
map cover https://tile.openstreetmap.org/{z}/{x}/{y}.png
# Naming the place you are in.
map names https://nominatim.openstreetmap.org/reverse?format=jsonv2&lat={lat}&lon={lon}&zoom={zoom}&accept-language=en
