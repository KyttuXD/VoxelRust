# The models the game itself draws: the player's hand.
#
# The game has no creatures of its own. The animals, the monsters, the villagers
# and the Wanderer are mods (wildlife, monsters, villagers, wanderer, in the
# VoxelRust-Mods folder), written by tools/gen_creatures.py and
# tools/export_mods.py; without them the world has no creatures.
#
# model <id> builtin <name>      a model that comes with the game (data/models/<name>.bbmodel)
# model <id> file <path>         a Blockbench model next to the pack file (see docs/DATA.md)

# The first-person hand: the player's own right arm, drawn with their skin.
# hand_slim is the same arm for slim (Alex-style) skins.
model hand builtin hand
model hand_slim builtin hand_slim
